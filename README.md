# LanFrame · 局域网审片

在局域网里互相审片、在画面上写批注的小工具，用法类似分秒帧、Frame.io，但视频不用上传：每个人的视频都留在自己电脑上，同事通过局域网直接播放原片，全程不需要外网。还能直接从同事电脑上拿文件（Win、Mac 之间都行）。Windows 和 Mac 都能用，双击就能运行，不用安装。

> 目前还是原型：审片的核心流程和拿文件只在一台 Mac 上用多个实例测过；在 Windows 电脑上、两台真实电脑之间目前只确认了互相发现和自动更新；浏览器只测过 Chrome 这类 Chromium 内核的。遇到问题欢迎反馈。

## 下载

到 [Releases](../../releases/latest) 下载最新版本：

- **Windows**：`lan-video-review-windows.exe`，下载后直接双击。
- **Mac**：`lan-video-review-mac.zip`，Apple 芯片和 Intel 芯片通用，需要 macOS 13 或更新的系统。双击解压后得到"局域网审片"，拖进"应用程序"文件夹再打开（直接在"下载"里打开的话，程序没法自动更新）。

装好以后程序会自己更新，不用再来这里下载（见下面的"自动更新"）。0.2.x 还没有这个功能，需要手动装一次 0.3.0 或更新的版本。

同事电脑上已经在运行这个程序的话，也可以直接用浏览器打开 `http://同事电脑的IP:28380`，从那里下载。

## 第一次打开

程序还没有正式签名，系统会拦一下：

- **Windows**：如果弹出"Windows 已保护你的电脑"，点"更多信息"→"仍要运行"。防火墙询问时选"允许"。
- **Mac**：如果提示"无法验证开发者"，打开"系统设置"→"隐私与安全性"，在下方点"仍要打开"。询问"查找本地网络上的设备"时选"允许"。

防火墙和本地网络这两项一定要允许，否则同事发现不了你，也播不了你的视频。

## 第一次设置

程序没有窗口，打开后会自动用浏览器打开界面（`http://localhost:28380`），并弹出设置：

1. **用户名**：同事看到的名字。
2. **团队口令**（可选）：设置后，只有填了相同口令的电脑才能看到你的视频和批注。团队里每个人都要填一样的；不填的话，局域网里谁都能看。
3. **本机共享目录**：建议新建一个专门的文件夹，不要选整个个人文件夹或整个磁盘。程序会在里面自动建三个子文件夹：
   - **分享**：放要给同事看的视频和文件。选的文件夹里原有的东西会挪进来（会先问你；剪辑软件工程里引用了这些文件的，会显示素材离线）。
   - **备份**：从同事那里拿来的东西，按来源分子文件夹，见下面的"从同事电脑拿文件"。
   - **批注**：所有批注和截图，电脑之间自动同步，不要手动删改。

   共享文件夹里的文件同事都能浏览和下载，只能拿，不能改、不能删；不想开放可以在"软件配置"里关掉。

点"开始使用"就好了。之后随时可以点右上角的"软件配置"修改，"使用说明"里有界面上的简要说明。

右上角只有三个按钮：

- **使用说明**：界面上的简要说明。
- **添加用户**：同事的电脑没有自动出现时，输入对方电脑的 IP 地址。
- **软件配置**：依次是基本信息（用户名、团队口令）、目录位置（本机共享目录）、运行选项（开机启动、静默运行、启动服务、允许同事下载我共享文件夹里的所有文件，改了立即生效）、本机信息（设备代码、本机 IP、程序版本和检查更新）。

## 日常使用

### 看片
- 左边列出你和同事分享的视频，绿点表示对方在线，红色数字是批注数。点一下就能播放，播放的是对方电脑上的原片，不压缩、不转码。
- 空格播放、暂停；← → 逐帧移动，按住 Shift 一次移动 10 帧。

### 写批注
1. 暂停到想说的那一帧，点"批注这一帧"或按 C。
2. 在画面上用自由画、箭头、方框、文字标出位置，下面写文字；可以添加图片，也可以直接粘贴截图。
3. 点"发布批注"，所有人都会看到。

- 点批注的缩略图或时间码，会跳到那一帧并显示画面标注；点批注文字可以展开全文和附图。
- 批注栏标题右边可以切换排序：按时间码，或者按批注时间。
- 自己写的批注可以"修改"（保留历史）和"删除"，别人的改不了。删除会同步清掉所有电脑上的这条批注。

### 回复
每条批注都可以点"回复"，回复显示在原批注下面。Ctrl+Enter（Mac 上 Cmd+Enter）发送，也可以加图片。自己的回复可以修改、删除。

### 分享视频
选中视频后，左边视频名下面有"备份视频"（只有同事的视频才有，见下面的"从同事电脑拿文件"）、"分享视频"和"导出批注"。"分享视频"会复制一段文字，可以直接粘贴到飞书、微信。同事点里面的链接，会在他自己的审片程序里直接打开这个视频。对方要先打开审片程序，最好用普通浏览器打开链接（飞书、微信里的内置浏览器也能用，但不太顺手）。

### 从同事电脑拿文件
- 左边同事名字旁有"文件"，点开能看到他共享文件夹里的"分享"和"备份"。勾选要的文件或文件夹（不同文件夹里的可以一起勾），点"下载"。对方不用在电脑前操作。
- 下载由程序在后台进行：关掉网页也会继续；断网、对方离线或者重启程序后，会从断点接着下（对方离线时显示"等对方上线"，上线后自动接着下）。左边列表底部会出现"下载中 N 项"，点开能看进度、取消、重试、打开所在文件夹；都结束后变成"下载记录"，清除后消失。
- 不要了的，在下载列表里点"删除"：拿来的文件移到废纸篓（Windows 是回收站），需要时还能找回来，这条下载记录也一起删掉。文件夹里还有别的东西（比如再拿一次时另存的"名字 (1)"）时，只移走这一项下载的文件。还在下的要先取消。
- 拿来的东西存在你共享文件夹的"备份/对方昵称/"里。从对方"备份"里转手拿的，仍然放在原来的来源下面。已经拿过、内容没变的文件不会再下一遍；对方改过的存成"名字 (1)"，不会覆盖。文件的修改时间和对方的一样。
- **拿来的视频就是原主人视频的备份**：列表里仍然在原主人名下，不算你的视频，也不会问"是不是新版本"。原主人不在时，同事能从你这里播放原片，批注是同一套，在备份上写的批注原主人回来后也能看到。原主人改了视频名称，你这边也会跟着变。
- 列表里优先显示原主人的文件；原主人那边已经删了（或者你从没见过原主人），才显示备份版，文件名下面有小字"备份版"。程序不会替原主人把文件复原回他的电脑。
- 只想备份某个视频的话，不用进"文件"里找：选中同事的视频，名字下面点"备份视频"就行。原主人不在时，会从存着备份、在线的同事那里拿。备份过的按钮变成"已备份"。
- Mac 和 Windows 的文件名规则不一样：Mac 上文件名里的 `? * : " < > |` 这些字符，拿到 Windows 上会换成 `_`。
- 拿过来的文件带着"来自其他电脑"的标记，和浏览器下载的、AirDrop 收到的一样：收到的程序第一次打开时系统会检查一下。视频和素材不受影响。
- 你的共享文件夹同事也能这样拿："批注"和隐藏文件除外，只能拿，不能改、不能删；设了团队口令的话，只有口令相同的同事能拿。不想开放的话，在"软件配置"里关掉"允许同事下载我共享文件夹里的所有文件"，同事仍然能看你的视频。
- 左边"我的视频"旁的"打开文件夹"会打开"分享"，要给同事看的东西放进去就行。
- 对方的程序要是 0.4.0 或更新的版本才有"文件"按钮，旧版本等它自动更新就好。

### 导出批注
视频名下面的"导出批注"，会把当前版本的所有批注导出成一个 .html 文件，带截图、画面标注和回复。浏览器打开就能看，也能打印成 PDF，方便发给不在局域网里的人。

### 版本和改名
- 重新导出的文件和之前的视频名字相近时（同名覆盖、`_v2`、`(1)` 等），程序会问你是不是新版本。确认后列在同一个视频下面，显示为 v01、v02……每个版本的批注各自独立，旧版本的批注保留。
- 自己的视频可以点"调整版本"，手动归到别的视频下面，或者单独拆出来。
- 自己的视频可以点"改名"，起一个视频名称（比如 `LAX43_EP03`），还可以顺便把电脑上的文件改成"名称_v版本号"（比如 `LAX43_EP03_v02.mp4`）。改名不影响批注。如果文件被剪辑软件的工程引用，改名后工程里会显示素材离线。
- 正在导出或拷贝的文件，写完十几秒后才会出现在列表里。

## 自动更新

- 程序在开机启动、手动打开、恢复服务时（平时每 6 小时）检查新版本，在后台下载好后，网页顶部和托盘菜单里会提示"新版本已经下载好"。点"立即更新"，程序重启几秒钟就换成新版本，网页会自动刷新。不着急的话可以点"稍后"。
- 更新时正在看你视频的同事会中断几秒，所以由你决定什么时候点。
- 新版本会先找局域网里的同事要：只要团队里有一台电脑从 GitHub 下载到了，其他电脑就从它那里拿，连不上外网也能更新。不管从哪里拿到的都会校验签名，别人冒充不了。
- "软件配置"里能看到当前版本和上次检查的结果，也可以点"检查更新"。
- 提示"不能自动换上"时：Mac 上多半是程序直接在"下载"文件夹里打开的，退出程序，把"局域网审片"拖进"应用程序"文件夹再打开就好；也可以点提示里的"手动下载新版本"自己替换。

## 让同事从你这里下载

同事用浏览器打开 `http://你的IP:28380`，就能看到下载页和安装引导。"添加用户"和"软件配置"里能看到你的地址。

程序会自己把当前版本的 Windows 和 Mac 安装包下载好（不管是自动更新的还是手动装的），下载页优先提供这些，不用做什么。还没下载好时（比如连不上 GitHub，局域网里也没有同事有），下载页提供的是你电脑上和程序放在同一个文件夹里的那两个文件，想让同事从你这里下载，就把从 Releases 下载的 `lan-video-review-windows.exe` 和 `lan-video-review-mac.zip` 都放在程序旁边：

- Windows：放在 .exe 所在的文件夹。
- Mac：放在"局域网审片"这个 app 所在的文件夹（比如都放在"应用程序"里）。

## 托盘和开机启动

- **托盘**：Mac 在屏幕顶部菜单栏，Windows 在右下角通知区域。菜单里可以打开界面、退出，还有三个开关，"软件配置"里也能改：
  - **开机启动**：登录电脑时自动打开程序。
  - **静默运行**：开机启动时不弹出浏览器，只在托盘里待命。
  - **启动服务**：关掉后程序留在后台，但不分享视频、不同步批注，同事那边显示你离线。
- 关掉浏览器页面不会退出程序；再次双击程序会重新打开界面。要退出，用托盘菜单里的"退出"。
- **换电脑**：新电脑上是新的身份，旧电脑上写的批注在新电脑上不能再修改和删除（大家仍然能看到）。

## 常见问题

**看不到同事？**
- 确认双方都开着程序、"启动服务"开着、在同一个局域网里。
- 团队口令要完全一样，不一样时界面会提示"团队口令不一致"。
- 第一次打开时如果没允许防火墙（Windows）或本地网络（Mac），需要去系统设置里补上。程序用 TCP 28380 和 UDP 28381 端口。
- 公司网络屏蔽了自动发现、或者不在同一个网段时，点"添加用户"，输入对方电脑的 IP 地址。

**视频放不了？**
浏览器只能播放常见编码：H.264 最稳；H.265 要看显卡和浏览器版本；ProRes 和 4:2:2 10bit 的 H.264 放不了。程序不做转码，审片前请导出 H.264。

**同事的视频突然播不了？**
视频在分享者自己的电脑上，他退出程序、关机或者电脑睡眠，视频就播不了，但批注和截图仍然能看。有同事把这个视频拿过去（备份）、并且在线的话，会自动从备份播放。分享视频期间，程序会阻止电脑自动睡眠，但合上笔记本盖子还是会睡眠。

**时间码和剪辑软件对不上？**
程序的时间码一律从 00:00:00:00 开始、按非丢帧计算。剪辑软件的时间线如果从 01:00:00:00 开始（DaVinci Resolve 的默认设置），或者用的是 29.97 丢帧时间码，时间码会对不上，但帧号是准的。另外，不同系统和浏览器显示的颜色略有差别，严格审色彩时不要以浏览器为准。

**Mac 上打不开共享文件夹？**
共享文件夹放在桌面、文稿、下载里时，Mac 会要求你允许访问。界面顶部会说明怎么做，允许后会自动恢复。从 0.2.x 更新到 0.3.0 后要重新允许一次，之后自动更新就不用再允许了。把共享文件夹放在这三个位置以外（比如在个人文件夹下新建一个），就不会被询问。

**更新到 0.4.0 后，剪辑软件里的素材离线了？**
0.4.0 把共享文件夹分成了三个子文件夹，原来直接放在共享文件夹里的视频和文件挪进了"分享"（批注文件夹从"批注同步(别删)"改名为"批注"）。剪辑软件工程里引用了这些文件的，在工程里把素材重新链接到"分享"里的同名文件就好，批注不受影响。共享文件夹是桌面、个人文件夹这类系统文件夹时，程序不会挪原有的文件。

**原主人删了视频，为什么别人还能看到？**
有人把视频拿过去以后，他那里就有一份备份，原主人删掉自己的文件，别人仍然能从备份看到，程序收不回来（批注也一样，见"写批注"）。不想被备份的视频，不要放进"分享"，或者在"软件配置"里关掉"允许同事下载我共享文件夹里的所有文件"。

**拿文件时提示磁盘空间不够？**
开始下载前会算好要下载多少，共享文件夹所在的磁盘不够时直接提示，不会下到一半才失败。

**WiFi 下卡顿？**
播放的是原片，没有"网速慢自动降清晰度"，网速不够只会缓冲。有线网络最稳。

**数据存在哪？怎么卸载？**
- 批注和截图：共享文件夹里的"批注"（0.3.x 叫"批注同步(别删)"，更新后自动改名）。
- 身份、日志、下载列表和下载好的新版本：Mac 在 `~/Library/Application Support/lan-video-review`，Windows 在 `%AppData%\lan-video-review`。
- 从同事那里拿的文件：共享文件夹里的"备份"，卸载时不会删。
- 卸载：先在"软件配置"里关掉"开机启动"，从托盘菜单退出程序，再删掉程序。上面的文件夹可以一起删（删了以后再装是新的身份）。
